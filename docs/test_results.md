## 💥 核心發現：2×2 ablation 在 test 上整個蒸發

val 上驅動我們提交決策的那套敘事（「31 維強度特徵有害、source-aware 有效」），在 test 上不成立：

| 系統 | 設定 | **A_PCC val (n=200)** | **A_PCC test (n=1,100)** |
|---|---|---|---|
| E4 | 10維L1，無 source-aware | 0.426 | 0.372 |
| E18 | 31維intensity，無 source-aware | 0.408 | 0.370 |
| E19 | 31維 + source-aware（**提交**） | **0.452** | **0.357** |
| E20 | ranking-only 增強 | 0.407 | 0.370 |

- **val 全距 0.045**（看起來 E19 明顯領先、E18 明顯落後）→ **test 全距僅 0.015**，且**排序完全打散**：
  val 上最高的 E19 在 test 上變**最低**，val 上被判「有害」的 E18 在 test 上與 E4 並列。
- 四個系統在 test 上全部落在 **0.357–0.372**，遠小於 n=1,100 的 A_PCC 95% CI 寬（0.103）。
- ⇒ **整個 2×2 消融的「結論」都是 val 上的抽樣雜訊。** source-aware、強度特徵、ranking 增強
  對 arousal **都沒有可偵測的真實效果**。這是論文 selection-overfitting 論點的最強實證：
  不只提交的那一顆選錯，是**整組據以做決策的排名都不可信**。

> **對論文的影響**：`docs/paper/outline.md` 中標為 ❌needs-evidence 的
> 「source-aware loss 改善 arousal」「31 維強度特徵有害」兩條 claim，
> test 證據顯示**兩者皆不成立** → 論文不得宣稱 source-aware 有效，
> 應改寫為「這些在 val 上看似有效的技巧，在 test 上都落在雜訊內」。

### ✅ label-free 訊號：test 上的 arousal 預測 spread（對抗壓縮的直接證據）

arousal 壓縮（pred std 偏小）是本任務 A_PCC 低的核心病灶。不需 gold 標籤即可算：

| 條件 | test A_pred std |
|---|---|
| 無增強 baseline | ~0.76 |
| N / A / C | 0.82 / 0.81 / 0.82 |
| **E**（圖擴散） | **0.85** |
| **F**（＋錨定） | **0.85** |
| **F2**（＋放寬長度） | **0.89** |

- **單調趨勢且方向正確**：C（查表 0.82）< E（圖擴散 0.85）< F2（0.89）。
- 圖擴散 + 錨定 + 放寬長度**逐步撐開被壓縮的 arousal 分布**，正是設計意圖。
- ⚠️ spread↑ 不保證 PCC↑（實驗 5 教訓：撐開不等於排序對）→ **須上傳 test 驗證是否轉成 A_PCC**。

### 💥 核心結論（C/E/F 已足以定調，F2 待補）

三件事在官方 test 上成立：

1. **圖結構對 A_PCC 沒有可測效果**：C 0.370 vs E 0.373，差 0.003，遠在 seed std（±0.01–0.02）內。
   儘管 E 的種子連貫度是 C 的 15.8 倍、test arousal spread 也更大（0.85 vs 0.82），
   **這些都沒有轉成 arousal 排序的提升**。
2. **增強完全沒提升 A_PCC**：C/E/F 全是 0.37，與無增強 baseline 0.372 **相同**。
3. **增強嚴重傷 A_MAE**：1.06–1.08 vs 無增強 0.93（+0.13～0.15）。
   ⇒ **實驗 5「A_PCC 撐開但 A_MAE 爆掉」的現象在 n=1,100 上完整重現**，且這次連 A_PCC 都沒撐起來。

> **對論文的意義（誠實但重要）**：「情感知識圖譜引導的可控生成能改善 arousal」這個原本要當主賣點的假說，
> **在官方 test 上不成立**——圖擴散不優於查表，增強不優於不增強，且都傷校準。
> spread 單調上升（C<E<F2）是真的、方向也對，但**撐開分布沒有轉成更好的排序**，
> 正是實驗 5b 早就警告過的。論文重心應誠實轉為：
> **「我們系統性地測試了圖引導生成的多個變體，在大測試集上證明它們對 arousal 均無效——
> 撐開 arousal 分布不等於改善其排序」**，與 selection-overfitting 主線合流成一個完整的 negative-result 故事。
> （待 F2 3 seed 補齊確認；若 F2 也 ~0.37，結論鎖定。）
